# Bot AI

Сканер котировок Pocket Option + AI Bot сигналы.

## AI Bot (мини-приложение в стиле Chat GPT Trade Bot)

- Выбор валютных пар (OTC и другие) с живыми котировками через WebSocket (po-demo).
- Таймфреймы: 5 сек, 15 сек, 1 мин, 3 мин, 5 мин, 30 мин, 1 час, 1 день.
- Анализ по индикаторам (тренд, поддержка, импульс, MA, RSI и т.д.) с анимацией.
- Сигнал ВНИЗ / ВВЕРХ с обратным отсчётом.
- Доступ по User ID в разделе Профиль (поддержка Telegram WebApp для автоматического ID).
- Вкладки: Сегодня, Сигнал, Профиль.

Котировки идут с демо-фида Pocket Option через WebSocket (`po-demo.js`). Для продакшена нужен реальный SSID/сессия.

## Запуск

```bash
npm install
npm start
```

Открой `http://localhost:3000`.

Для Telegram Mini App задай `BOT_TOKEN` и `WEBAPP_URL`.
